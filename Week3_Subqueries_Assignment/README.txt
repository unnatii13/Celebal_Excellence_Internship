Week 3 - SQL Assignment (Subqueries, CTEs & Window Functions)

## Objective

Analyze the Superstore dataset using SQL by applying advanced SQL concepts such as:

- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- JOIN Operations
- Aggregate Functions

## Dataset

## SQL Concepts Used

- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
  - RANK()
  - ROW_NUMBER()
- Aggregate Functions
- INNER JOIN
- GROUP BY
- ORDER BY

---

## Business Questions Solved

1. Find orders where sales are greater than the average sales.
2. Find the highest order value for each customer.
3. Calculate total sales for each customer using a CTE.
4. Find customers whose total sales are above the average customer sales.
5. Rank customers based on total sales.
6. Assign row numbers to orders for each customer.
7. Display the Top 3 customers by sales.
8. Display the Top 5 customers by sales.
9. Display the Bottom 5 customers by sales.
10. Find customers who placed only one order.
11. Find the highest order value for every customer.
